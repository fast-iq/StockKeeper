---
name: Секреты публикации
description: Не делать вывод о подключении Production-БД только по видимости секрета в рабочем пространстве.
---

Пользователь задаёт `EXTERNAL_DB_URL` для Production в настройках публикации Replit. Отрицательный результат просмотра секретов проекта сам по себе не доказывает, что ключ отсутствует в настройках опубликованного приложения.

**Why:** просмотр секретов проекта не показывал ключ, а пользователь уточнил, что добавил его именно в настройки публикации. Документация различает настройки рабочего пространства и deployment secrets.

**How to apply:** перед выводом о выбранной Production-БД уточнить сохранение секрета в Publishing и повторную публикацию после его изменения. Успешный вход до этого изменения не подтверждает переключение БД. Запросы через встроенный инструмент Production SQL относятся только к управляемой БД Replit, не к внешней.
