---
name: Браузер для изолированных тестов
description: Почему установка Playwright Chromium через CLI не гарантирует доступность браузера для защищённого browser-runner.
---

Для изолированных browser-тестов в Replit предпочитать уже установленный системный Chromium, передавая его путь через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

**Why:** установка Playwright через CLI записала браузер в workspace-cache, а защищённый тестовый процесс искал его в домашнем cache другого окружения. Системный Chromium устранил зависимость от этих различающихся путей.

**How to apply:** сначала проверить `command -v chromium` и существование возвращённого файла. Передать этот путь только в команду теста; не устанавливать второй браузер, пока не проверен доступный системный. Не менять allowlist секретов и не использовать рабочую БД ради запуска тестов.
