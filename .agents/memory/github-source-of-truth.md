name: GitHub и AGENTS.md
description: Пользовательские правила актуальности исходников и сопровождения AGENTS.md в StockKeeper.
---

Перед каждой задачей проверять GitHub: пользователь дорабатывает приложение там, и там находится самая актуальная версия. До внесения изменений обновить рабочую копию из GitHub, не затирая несохранённые локальные правки.

Перед каждой задачей читать актуальный AGENTS.md и учитывать описанные изменения и инварианты. При собственных изменениях проекта обновлять этот файл.

**Why:** пользователь прямо попросил соблюдать эти правила, чтобы не сломать доработки, сделанные другими разработчиками.

**How to apply:** сначала проверить актуальную ветку GitHub и локальную рабочую копию, синхронизировать исходники, затем прочитать AGENTS.md и только после этого править приложение. Если синхронизация недоступна, не продолжать на устаревших исходниках; запросить актуальный архив или доступный способ синхронизации.

Чистое рабочее дерево не означает, что собственные изменения уже отправлены в GitHub: Replit checkpoints могут сохранить их локальными коммитами.

**Why:** автоматические checkpoints отделены от публикации изменений в GitHub; импорт архива способен незаметно затереть ещё не отправленные доработки даже при чистом `git status`.

**How to apply:** перед повторным импортом или синхронизацией проверить также локальные коммиты/расхождения с GitHub, а не только незакоммиченные файлы. Сохранять собственные непереданные изменения и при конфликте согласовать способ объединения.
