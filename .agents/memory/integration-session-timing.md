---
name: Timing of authenticated API tests
description: Why tests must finish consuming a login response before using its session cookie.
---

В API-тестах получение заголовков ответа входа не означает завершение сохранения
сессии. Дочитывать тело ответа до следующего запроса с полученной cookie.

**Why:** Express может передать заголовки до завершения асинхронного сохранения
сессии PostgreSQL. Следующий запрос, отправленный сразу после получения
заголовков, иногда видит ещё отсутствующую сессию и возвращает 401.

**How to apply:** в новых HTTP-тестах аутентифицированных сценариев дождаться
чтения тела ответа входа. Не устранять эту гонку sleep, повторными запросами
или ослаблением production-аутентификации.
