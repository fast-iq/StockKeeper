---
name: Прерывание браузерных тестов
description: Последствия внешнего лимита времени для очистки изолированного тестового стенда в Replit.
---

Принудительное завершение браузерного прогона внешним лимитом времени
может обойти очистку стенда и оставить сгенерированные JS-бандлы в рабочем
дереве. Последующий lint может сообщить сотни ошибок в этих временных
файлах, хотя исходники проходят проверку.

**Why:** в Replit полный набор браузерных сценариев не успел завершиться
за пять минут; оставшиеся временные бандлы дали ложные ошибки lint.

**How to apply:** после прерванного прогона отличать ошибки исходников
от ошибок в созданных этим прогоном временных файлах. Проверять, что
процесс завершён, и очищать только его собственные временные артефакты,
не пользовательские данные. Для длинного прогона обеспечивать достаточный
внешний лимит времени или запускать отдельные группы с полной отчётностью.
