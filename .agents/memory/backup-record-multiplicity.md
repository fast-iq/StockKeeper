---
name: Количество одинаковых записей в копии
description: Почему skip-импорт должен сопоставлять записи один к одному, а не удалять одинаковые записи внутри файла.
---

В режиме «Пропускать совпадения» разные исходные ID товаров и цен должны оставаться разными записями. Совпадение реквизитов не означает, что две исходные записи — одна сущность.

**Why:** копия товара может иметь те же реквизиты, что оригинал, но самостоятельную историю цен. Объединение одинаковых записей при восстановлении в пустой аккаунт смешивало эти истории и теряло отдельные записи цен.

**How to apply:** каждую существующую запись использовать как совпадение не более одного раза за импорт. Не использовать только что созданные записи для пропуска следующих строк этого же файла. Проверять сохранение количества одинаковых записей, независимость связанной истории и отсутствие новых записей при повторном импорте.
